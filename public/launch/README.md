# WhyLab launch kit

These repository-owned assets use one consistent message and synthetic data only.

- `whylab-thumbnail.svg` — 1270×760 Product Hunt thumbnail.
- `gallery-1-input.svg` — evidence input and consent boundary.
- `gallery-2-activity.svg` — observable Astra-selected diagnostic activity.
- `gallery-3-evidence.svg` — evidence graph and falsification criterion.

The gallery visuals are launch illustrations, not screenshots of a live Astra
run. Replace or supplement them with captured production screenshots after the
public deployment and successful live investigation are available. Never put
`.env.local`, API keys, provider reasoning payloads, or real patient data in
launch material.
